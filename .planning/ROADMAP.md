# Roadmap: AI Judge (न्याय-AI)

## Phase Structure & Execution Milestones

```
[Phase 1: Foundation & Design] ──► [Phase 2: Adversarial Engine] ──► [Phase 3: Evidence Forensics]
                                                                                │
[Phase 5: Verification & Ship] ◄── [Phase 4: Serverless Decree Synthesis] ◄─────┘
```

---

### Phase 1: Sovereign Design & Constitutional Foundation
- [x] **Goal**: Establish the next-generation sovereign visual identity for the Indian Judiciary.
- [x] Integrate Ashoka Lion emblems, Court tier badges (Supreme Court, High Court, District Court).
- [x] Implement comprehensive case records and multi-tier routing (`/text-courtroom/[id]`, `/dashboard`, `/cases`, `/evidence`).
- [x] Standardize bilingual typography and court terminology (Order XX CPC, Article 142, Section 480 BNSS).

---

### Phase 2: Adversarial Courtroom Simulation (Muse Spark Open)
- [x] **Goal**: Integrate Meta's official open-weights reasoning model `meta-models/muse-spark-open-1026` via Baseten.
- [x] Build dual-counsel debate loop: Petitioner Senior Counsel vs. Respondent Defense Counsel.
- [x] Implement AI Presiding Judicial Officer ruling turn with precedent citations.
- [x] Tune reasoning parameters (`reasoning_effort: 'low'`, `max_tokens: 4000`) to prevent scratchpad leakage and token truncation.
- [x] Cleanly sequester Chain of Thought deliberation into the interactive accordion UI.

---

### Phase 3: Multimodal Forensic Evidence Analysis (SAM 3.1)
- [x] **Goal**: Deploy Meta's Segment Anything Model 3.1 for digital evidence verification.
- [x] Implement interactive `ForensicEvidenceViewer` component with zoom, pan, and segmented overlay masking.
- [x] Validate notary seal integrity, stamp authenticity, and pen-stroke continuity under Section 63 BSA.
- [x] Compute cryptographic SHA-256 certificate hashes for court custody chain verification.

---

### Phase 4: Serverless Judicial Decree Synthesis (Modal Cloud)
- [x] **Goal**: Implement deterministic legal arithmetic and decree synthesis via Modal Serverless Python engine.
- [x] Build `modal_backend/legal_engine.py` with endpoints for interest calculation, contract breach mitigation, and Order XX decrees.
- [x] Integrate financial recovery matrix (Principal, 24% quarterly compounding statutory interest, taxed costs).
- [x] Apply *Kailash Nath Associates v. DDA* caps on liquidated damages under Section 74 Indian Contract Act.

---

### Phase 5: Verification Gate & Hackathon Packaging (Meta Agent Architecture)
- [x] **Goal**: Enforce Meta's official "Trustworthy Legal Agent" architecture.
- [x] Implement automated 3-stage **Statutory Verification Checklist Gate** (`verify_checklist`) in the decree synthesis flow.
- [x] Incorporate insights from Meta's official legal agent workshop and Fireworks benchmark findings.
- [x] Package institutional documentation, clean codebase mapping, and zero-defect test verification.
